About SchoolSync

Attendance, without the guesswork.

SchoolSync is a barcode & QR-based attendance monitoring system built to make daily check-ins fast, accurate, and visible to everyone who needs it — admins, teachers, and students.

How it works

Three steps. Zero confusion.

1

Register

The admin registers each student with their name, ID number, department, and section. A unique QR code is generated automatically for each student.

2

Scan

Students scan their QR code using any camera or the built-in scanner. The system records the time and automatically marks them Present or Late based on the cutoff time.

3

Monitor

Teachers and admins see attendance in real time. Records can be filtered by date, edited, and reviewed at any time from any device.

Who uses SchoolSync

A role for everyone in the school.

Admin

Registers students and teachers, runs the QR scanner, manages all attendance logs, and has full access to every record and setting in the system.

Teacher

Views My Class attendance by date, manages their weekly schedule, edits student statuses, and can access the admin panel when needed.

Student

Scans their personal QR code to check in, views their own attendance history, sees the class schedule, and carries a digital ID card.

The system

Built on the web. Works everywhere.

No app install needed. SchoolSync runs entirely in the browser and works on phones, tablets, and desktops. Built with Node.js and MySQL, deployed on Railway.
